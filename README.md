# Life Insurance Simulator

Python tool for estimating annual and monthly life insurance premiums based on age, insured capital, contract term and mortality data.

The project generates a lightweight HTML dashboard for quick visualization and uses Pandas, NumPy, Plotly, Matplotlib and Seaborn.

## Features

- Premium estimation from actuarial inputs
- Annual and monthly premium breakdown
- Mortality-data based calculations
- HTML dashboard for visual inspection
- Python workflow suitable for experimentation and extension

## Tech Stack

- Python
- Pandas
- NumPy
- Plotly
- Matplotlib
- Seaborn
